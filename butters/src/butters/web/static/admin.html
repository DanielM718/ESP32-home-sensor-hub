Credential

Butters shows the state of the credential, never its value. A stored key is not returned by any endpoint, is not written to logs, audit records, or job payloads, and never reaches this page.

Select Credentials to load credential state.

The candidate is validated against OpenAI before it replaces anything. If validation fails the existing credential stays active and the candidate is discarded. Use a project key scoped to Butters rather than a general-purpose key.

No credential operation has been requested.

Removing the credential here deletes only Butters’ local copy. It cannot revoke anything in your OpenAI account; revoke the key in the OpenAI Platform if it is no longer needed.

OpenAI usage reporting

Checking…

A separate organization Admin API key, used only to read what OpenAI says was spent. It is never passed to Chat, speech or transcription.

Create it in the OpenAI organization settings with Usage API Scope: Read and every other permission left at None — Butters needs nothing else, and in particular needs no Organization Administration, Audit Logs or Fine-tuning access. It is still an organization-level credential, so it is stored and gated like one: Butters only ever issues GET requests to three reviewed endpoints and can express no organization mutation.
